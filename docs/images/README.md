# Изображения архитектуры

Эта папка содержит изображения и диаграммы архитектуры программного средства.

## Рекомендуемые форматы
- PNG — для диаграмм и схем
- SVG — для векторных изображений
- JPG — для фотографий интерфейсов

## Структура
Размещайте изображения с понятными именами:
- `architecture-overview.png` — общая архитектура системы
- `data-flow.png` — диаграмма потоков данных
- `components-diagram.png` — схема компонентов
- `deployment-diagram.png` — схема развертывания
